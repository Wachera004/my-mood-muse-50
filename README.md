
# My Mood Muse 🧘‍♀️

A sleek, intuitive mood-tracking application designed to help users monitor their emotional well-being through a modern web interface. This project serves as a showcase of responsive frontend design and seamless state management.

## 🌟 Key Features
* **Daily Logging:** Quickly capture your current mood with a user-friendly interface.
* **Emotional Analytics:** Visualize mood trends to better understand personal well-being patterns.
* **Responsive UI:** Fully optimized for a seamless experience on both mobile and desktop devices.
* **Persistent Data:** Ensures your history is maintained throughout your journey.

## 🛠️ Tech Stack
This project is built using modern web technologies:
* **Frontend Library:** [React](https://reactjs.org/)
* **Language:** [TypeScript](https://www.typescriptlang.org/) 
* **Build Tool:** [Vite](https://vitejs.dev/) 
* **Styling:** [Tailwind CSS](https://tailwindcss.com/) & [shadcn/ui](https://ui.shadcn.com/)
